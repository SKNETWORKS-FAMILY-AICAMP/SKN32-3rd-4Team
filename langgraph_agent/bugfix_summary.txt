[langgraph_agent] 버그 수정 정리 (팀 공유용)

■ 먼저 읽으면 좋은 파일 (우선순위 순)
1. graph/precheck_graph.py - 계약 기준 그래프 본체, 이번에 제일 많이 바뀜
2. graph/precheck_domain.py - 위 그래프가 쓰는 타입 정의
3. graph/citation_guard.py - 인용 검증기 (신규 파일)
4. nodes/mcp_caller.py - 도구 호출 담당, 버그 여러 개 있었음
5. main.py - 진입점, 어떤 그래프를 부르는지 바뀜
나머지(router.py, state.py, result_parser.py, judge_coverage.py)는 그래프A(프로토타입) 쪽이라 우선순위 낮음


■ 파일별 변경 사항

nodes/mcp_caller.py
- policy_rag가 요청됐으면 다른 intent(disease_lookup 등)가 성공해도 약관 조항이 반드시 있어야 통과하도록 수정 (하나만 성공해도 통과되던 버그)
- 일부 intent만 실패했을 때 error가 최종 답변에 안 들어가고 조용히 사라지던 것 수정 (judge_coverage.py와 연계)
- 그래프A에 없던 질병기호 해시 보호 추가 (disease_code_hash 필드, graph/privacy.py로 해시 로직 공용화)
- 타임아웃 후에도 스레드가 안 죽어서 반복 타임아웃 시 스레드풀이 고갈되고 이후 모든 호출이 먹통 되던 버그 수정 (호출마다 격리된 1-worker executor로 교체)

graph/state.py
- citations(판정근거, 약관조항만) / references(참고자료, 유사사례·통계·용어) 필드 분리 추가
- disease_code_hash 필드 추가 (로그/트레이스는 이걸 참조, disease_code 평문은 도구 호출용으로만 사용)

nodes/result_parser.py
- 위 분리에 맞춰 citations/references 각각 채우도록 로직 분리

nodes/judge_coverage.py
- 프롬프트에서 "약관조항만 판정근거, 나머지는 참고정보"라고 명확히 구분
- 이게 프로토타입이고 계약 준수 버전은 precheck_graph.py라는 docstring 추가
- 일부 intent 실패 시 error를 최종 답변 뒤에 경고문으로 결정론적으로 덧붙이도록 수정

graph/router.py
- json.loads("null")이 None을 반환할 때 리스트 컴프리헨션에서 죽던 버그 수정 (isinstance 체크 추가)
- 분류 실패 시 가장 위험한 policy_rag로 임의 확정하던 기본값 제거 (실패는 그냥 빈 리스트로)

graph/precheck_domain.py
- Citation에 qualified_no/clause_id 필드 추가 (인용 특정용)
- PrecheckOutcome에 cited_handles 필드 추가
- ReasonCode 값 대소문자 혼재(정본은 소문자 snake_case)를 전부 소문자로 통일

graph/precheck_graph.py
- 자체 정규식 인용검사(_ARTICLE_PATTERN) 제거하고 citation_guard.verify()로 교체
- explain/verify 인터페이스를 손잡이(E001) 기반으로 재설계, LLM 응답 파싱 함수(parse_explain_output) 추가
- 인용문 자기참조 버그(quotes 파라미터) 제거
- normalize→rules→verify 세 덩어리로 뭉쳐있던 토폴로지를 계약 다이어그램대로 resolve_policy/gate_document/retrieve/assess/explain 5개 독립 LangGraph 노드 + 조건부 분기로 분해
  (retrieve가 실패하면 assess/explain이 아예 호출조차 안 되는 것, invoke()와 실제 LangGraph 실행이 동일한 trail을 만드는 것까지 직접 확인함)
- 인용검증 실패 시 재시도(verify_citations)가 build()에서 배선이 안 돼 실제로는 한 번도 재시도가 안 일어나고 있던 버그 발견 및 수정
  (조항을 다시 검색하지 않고, 세대 필터를 통과한 같은 근거로 explain만 다시 호출하는 방식으로 재시도 - 세대 다른 조항이 섞여 들어오는 걸 방지)

main.py
- 그래프A(graph/builder.py) 대신 그래프B(precheck_graph.py)를 실제로 부르도록 전면 교체

graph/citation_guard.py (신규 파일)
- 인용 검증기 v2. 조항마다 요청단위 손잡이(E001)를 붙여 LLM이 그걸로만 인용하게 하고, 손잡이 해소/모호성/미선언 인용을 fail-closed로 검증

graph/privacy.py (신규 파일)
- 질병기호 해시 공용 유틸 (그래프A/그래프B가 같이 씀)

requirements.txt
- 개발 환경에 프로젝트 의존성이 애초에 하나도 안 깔려있던 것 발견
- langgraph==0.6.11 등 실제로 같이 동작하는 버전 조합으로 전부 고정 (langchain-core 버전 충돌 있었음)
