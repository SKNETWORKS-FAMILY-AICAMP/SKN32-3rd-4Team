## 0. 이 문서를 쓰는 법 — ★가장 중요한 규칙

### 0-1. 「검수」와 「구현」을 섞지 않는다

이게 코덱스와 합의한 **제1원칙**이다.

> **구현이 없는 것을 체크리스트에 두면 매번 "실패"로 잡히고, 시간만 쓴다.**
> 그건 검수 항목이 아니라 **구현 목록**이다.

각 항목에 태그를 붙였다.

| 태그 | 뜻 |
|---|---|
| **[검수]** | 지금 확인할 수 있다. 통과/실패가 의미 있다 |
| **[구현]** | 확인할 대상이 없다. §D 목록으로 옮긴다 |
| **[결함]** | 이미 확인된 결함. 재현만 하고 넘어간다(§E) |

### 0-2. 순서 원칙 — 안전모드부터

★**코덱스 반박을 수용한 부분이다.** 내 초안은 *"판정 가능한 약관이 0건이면 그 뒤는 전부 공회전"* 이라 했는데
**과했다.** 막히는 것은 **긍정 E2E 하나뿐**이고, 아래는 confirmed 문서가 0건이어도 전부 검수된다.

- 입력 검증 · 기권 경로 · 무폴백 · 데이터 게이트
- 규칙·도메인 단위 테스트
- 물리 데이터 품질
- 문서·계약 정합성

그래서 **§A(안전모드)를 먼저 전부 끝내고**, 그다음 §B(골든 약관 1건 확정 후 E2E)로 간다.
§A 는 다른 사람의 작업을 기다리지 않는다.

### 0-3. 결과 기록

각 항목 옆에 `✅ / ❌ / ⏭(구현없음)` 과 **관측한 값 원문**을 적는다.
"됐다/안됐다"만 적으면 나중에 재현이 안 된다.

## §B. 골든 약관 1건 확정 후 E2E — ★선행조건 있음

★**코덱스 반박 수용**: *"confirmed 1건 만들기"* 는 **검수가 아니라 구현**이다.
JSON 을 손으로 고쳐 넣는 것은 **승격 기능을 검수한 게 아니다.**

**선행조건**: 식별 확정(승격) 경로가 코드로 존재하고, 감사 로그가 남을 것.
그게 없으면 §B 는 시작할 수 없다 → §D-1 로 간다.

선행조건이 갖춰지면:

| # | 확인 | 통과 기준 |
|---|---|---|
| B-1 | 문서 1건 확정 후 manifest 의 total 이 0 → 1 | 숫자가 움직인다 |
| B-2 | ★**확정 행위가 감사 로그에 남는가** | 누가·언제·무엇을 근거로 |
| B-3 | 그 보험사로 요청 시 `insurer_not_supported` 소멸 | — |
| B-4 | 판정 결과에 `applied_policy` 가 채워진다 | `sha256` 까지 |
| B-5 | `citations[]` 가 실재 조항을 가리킨다 | 쪽수로 **원문 PDF 를 열어 대조** |
| B-6 | 면책 조항이 **함께** 나오는가 | 보장 조항만 나오면 실패 |
| B-7 | ★manifest 가 **제외된 나머지의 사유별 건수**를 보여주는가 | 안 보이면 **1건 성공 뒤 조용한 스킵이 감춰진다**(코덱스) |

## §E. 이미 확인된 결함 — 재현만 하고 넘어간다

### E-1. ★`date_confidence` fail-open (P0)

```python
# app/adapters/manifest_policy_resolver.py:51
date_confidence=r.get("date_confidence", "exact"),
```

필드가 **없으면 `"exact"`** 가 된다. 그런데 게이트는

```python
# app/core/ports/precheck.py:95
if self.date_confidence not in ("exact", "month"): return False
```

**즉 "모른다"가 "확실하다"로 바뀌어 게이트를 통과한다.**
바로 옆 줄의 `identification` 은 `or "unidentified"` 로 **fail-closed** 인데 이것만 반대다.

### E-2. ★검증 등급 어휘가 두 벌 (P0)

| 곳 | 어휘 |
|---|---|
| 도메인·ERD·스토리보드 | `verified` 만 집계 |
| `app/adapters/file_cohort_stats.py:40` | `_COUNTED = {"document_backed", "confirmed"}` |
| `docs/handoff/03` §3 | `unverified/self_reported/document_backed/confirmed` |

**같은 것을 두 이름으로 부르면 반드시 갈라진다.** 어느 쪽이 정본인지 정해야 한다.

### E-3. 코덱스가 제기했으나 **내가 미확인**인 것

정직하게 구분한다. 아래는 **확인하고 넘어갈 것**이지 확정된 결함이 아니다.

- SHA 중복 제거로 판매 occurrence 일부 손실(418건 중)
- `trace_id` 가 실행별 감사 ID 가 아님
- observations 가 `model_dump()` 를 저장해 "원본 그대로 보존"이 아님
