## 1. 코덱스가 뒤집은 내 초안 셋 (기록)

**① S1 층화 축을 잘못 잡았다.**


진짜 1차 분류는 **원본 PDF 에 그 헤더가 실재하는가**다.

| 판정 | 뜻 |
|---|---|
| A2 헤더가 원본 word/bbox 에 없음 | 본문·표를 헤더로 오인 |
| B 헤더가 없음 | **B 가 거짓 경계** |
| A·B·A 모두 실재 | 부모/section 경계 누락 |
| 동일 bbox·텍스트 재사용 | 중복 추출 |
| 좌표·페이지 순서 역행 | reading-order 결함 |
| 다른 추출 모드에서 정상 | 모드 의존 결함 |

**② S2 는 게이트 대상 자체가 틀렸다.**
번호가 진짜 빠졌다고 확인돼도 **A·B 가 잘못된 게 아니다.** 이웃 ordinal 을 끄면 안 되고,
**그 페이지/문서의 completeness 를 게이트하고 재추출**해야 한다.
`B` 를 조항 게이트하는 건 **B 가 거짓 헤더로 확인된 경우에만**.

또 전체 게이트는 불가능하다. 고정밀 부분집합만 승격한다(실측: 같은 페이지 95.7%,
단일 결번 18.9% — 페이지·gap 크기는 강한 신호가 아니다).

**③ 부록 recall 은 정답셋 없이 못 잰다.** proxy 만 가능하다.
번호 연속성(`별표1..N`)은 **가장 약한** 신호다 — section 마다 번호가 재시작하고
무번호 부록·의도적 결번이 있다. 실제 recall 을 말하려면 층화 표본 사람 판정이 필요하다.
