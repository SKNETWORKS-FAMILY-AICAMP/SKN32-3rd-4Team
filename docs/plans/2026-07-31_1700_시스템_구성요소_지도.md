    L3   │ 판정: 적용약관버전 확정 → 규칙엔진(코드) → 4단 판정 │ ①

        │ + 신선도 게이트      │             │ 코호트 집계          │ ①③

    L6   운영: 관리자 콘솔(교차검증·Ambiguous 검수·지식갭 큐)·관리자 보고서   ③⑤

## 3. ⚠ 상호작용 RAG — 필요하지만, **지식이 아니라 신호다**

"에이전트가 와서 소통하고 그래서 쌓이는 정보"를 검색 가능하게 만드는 것은 맞다.
다만 **그것을 약관 RAG와 같은 층에 두면 제품이 무너진다.**

### 세 가지 위험

| 위험 | 내용 |
|---|---|
| **순환 참조** | 우리가 생성한 답변이 색인에 들어가고, 다음 질문의 근거로 다시 인용된다. **근거의 출처가 우리 자신**이 된다 |
| **코퍼스 오염** | ★주 고객이 외부 에이전트다. 상호작용이 그대로 색인되면 **외부에서 우리 지식베이스에 텍스트를 심을 수 있다.** 악의가 없어도 잘못된 전제가 대량 유입된다 |
| **사실성 착시** | 같은 질문이 500번 들어왔다는 건 **그 답이 맞다는 뜻이 아니다.** 빈도를 신뢰도로 착각하기 쉽다 |

### 규칙

```
상호작용 로그 ─┬─→ [운영 신호]  무엇을 못 답했나 · 무슨 질문이 많나 · 어디서 abstain 했나
               │                → 지식갭 큐 → ★사람 검수 → FAQ/문서로 승격 → 그때 L2 진입
               └─✗ 판정 근거 인용  ← 절대 금지
```

- **별도 인덱스.** 약관 RAG와 병합·UNION 금지(합성/실제 분리와 같은 원칙).
- **판정 근거 인용 대상에서 제외.** 판정의 근거는 약관 조항과 `verified` 증빙뿐이다.
- **L2로 올라오는 유일한 통로는 사람 검수를 거친 승격**이며, 그때 출처가 "내부 FAQ"로 바뀐다.
- PII 마스킹 후 저장(기존 지식갭 큐 자산 재사용).

> 이것은 새 원칙이 아니다. **`consistent`가 `verified`가 아니듯, 자주 물어본 것이 사실은 아니다.**

## 4. ⚠ 주 고객이 에이전트라면 — API를 여는 것으로 끝나지 않는다

### 사람과 에이전트는 불확실성을 다르게 소비한다

사람은 화면 구석의 "표본 12건" 회색 글씨를 보고 **알아서 감안**한다.
**에이전트는 필드가 없으면 그냥 무시하고, 자기 사용자에게 단정적으로 전달한다.**

→ **불확실성은 문장이 아니라 필드여야 한다.**

| 필드 | 의미 |
|---|---|
| `data_source` | `synthetic` / `verified_real` — ★최우선 |
| `n`, `min_sample_met` | 표본수와 최소표본 충족 여부 |
| `verification_method` | `admin_review` 등 — 무엇으로 검증했나 |
| `abstained`, `abstain_reason` | 답을 안 한 것과 못 한 것을 구분 |
| `missing_documents` | 무엇이 더 있어야 판정되나 |
| `as_of`, `policy_version` | 언제 기준·어느 약관 버전 |
| `warnings[]` | 생존편향·선택편향 등 |

### 에이전트 전용으로 필요한 것

| 요소 | 이유 |
|---|---|
| **신원·인증** | 익명 에이전트에게 민감 판정을 주지 않는다 |
| **레이트리밋** | 에이전트는 사람보다 **수백 배 빠르게** 호출한다. 사람 기준 제한은 무의미하다 |
| **남용 방지** | 대량 조회로 코호트 분포를 역추론해 개인을 특정하려는 시도 차단 |
| `llms.txt` / OpenAPI | 에이전트가 **문서를 읽고 스스로 쓸 수 있어야** 한다 |

## 6. 한계 (정직 기록)

- 이 지도는 **구성요소 목록**이지 설계서가 아니다. 각 요소의 포트 시그니처는 P0에서 확정한다.
- 25개는 4주에 다 만드는 목록이 **아니다.** §5의 MVP 열만 4주 대상이다.
- 상호작용 RAG(19)는 **MVP에서 "수집·저장·지식갭 큐"까지만** 한다. 검색 UX는 후순위다.
