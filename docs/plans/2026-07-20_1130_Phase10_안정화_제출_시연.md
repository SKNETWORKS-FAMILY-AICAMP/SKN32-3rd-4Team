## 2. 설계
### (a) 요구사항 매트릭스 (`tests/requirements_matrix.yaml`)
Phase 1~9에서 실제로 구현·테스트된 것만 기입한다(계획서의 열망이 아니라 **실측**).
각 REQ에 대해: 설명, 구현 위치, 검증 pytest node id(들), 상태(DONE). 매트릭스 자체를
**정적 스캔 테스트**(`TEST-MATRIX-001`)로 검증한다.
**collect 가능 여부만으로는 부족하다**(Codex 지적 (a)) — 매트릭스가 "존재하는 테스트를
가리키기만" 해도 통과해버리면 가짜로 그럴듯한 매핑을 못 걸러낸다. 추가로 검증할 것:
- **skip/xfail 금지**: 매핑된 테스트가 `@pytest.mark.skip`/`xfail`이면 실패(이름만 있고
  실행 안 되는 매핑 방지).
- **REQ당 최소 1개 이상**의 실행 가능한 node이며, 같은 node를 여러 REQ가 중복 재사용할 때는
  각 REQ가 그 테스트의 assertion과 실제로 관련 있는지 **매트릭스 작성자(나)가 근거 문구를
  같이 적어** 리뷰 가능하게 한다(자동 검증 한계는 인정 — §5에 명시).

**#7 신규 검증**: `_load_docs`가 `glob("*.txt")`/`glob("*.pdf")`로 비재귀·확장자 고정이라
구조적으로 안전해 보이나 테스트로 고정된 적이 없다. 하위 폴더 파일 미수집·비허용 확장자
(.py/.env 등) 미수집을 테스트로 잠근다.
**위협모델을 정직하게 기록한다(Codex (b))**: `docs_dir`은 CLI 운영자가 설정하는 값이라
원격 공격자가 통제할 수 없다 — 이번 테스트는 "취약점 없음 증명"이 아니라 **불변식 고정**이다.
경로 정규화(symlink 탈출 등)는 다루지 않으며, 이 도구가 향후 업로드 API 등 사용자 입력을
받게 되면 **그때는 반드시 재검토**해야 한다는 잔여위험을 리포트에 명시한다.
**8개는 기존 테스트를 매트릭스에 연결**한다 — Codex도 "이름만 비슷하거나 간접효과만
확인하면 보강, 위협·입력·기대 속성이 assertion까지 추적되면 재사용 정당"이라고 판단.
연결 시 각 REQ 옆에 **해당 테스트의 assertion이 무엇을 직접 확인하는지 한 줄 근거**를 적어
"간접효과만 확인" 여부를 리뷰 가능하게 한다.

### (c) 결정론 — "100%"가 아니라 "2회 재현성 확인"으로 정직하게 표현(Codex (d))
`pytest -m "not llm and not ml and not pg and not mcp"`를 **연속 2회** 실행해 같은 결과가
나오는지 확인한다. 이것은 "완전한 결정론 증명"이 아니라 **재현성 확인**이라고 리포트에
정확히 표현한다(2회 통과가 100% 결정론을 증명하지 않는다는 한계를 명시).

### (d) 실모델 1 smoke — 환경 고정 명시
기존 llm 마커 테스트 중 1개를 골라 **실제로 로컬 모델 서버를 켜서** 통과를 확인한다.
사용한 **모델 ID·temperature·서버 버전**을 리포트에 기록한다(재현 절차 명시, Codex (d)).
연결 실패 시 InfraError로 명시 실패하는지도 함께 확인(무폴백).

### (e) 시연 스크립트 — 실패 경로도 숨기지 않는다(Codex (d))
`scripts/demo.py` — RAG(하이브리드) → GraphRAG → 커머스 승인 루프(미리보기→승인→멱등) →
MCP(REST와 parity) → 관리자(RBAC) 를 순서대로 실행. **성공 경로만 보여주지 않는다**:
- 승인 루프에서 재고부족 422·같은 키 다른 payload 409 등 **거부 경로도 함께 시연**.
- MCP 호출이 실패하면(서버 미기동 등) 그 실패를 있는 그대로 출력하고 스크립트가 죽지
  않게 하되(각 섹션 독립 실행), "성공한 것처럼" 넘어가지 않는다.
LLM 미기동 환경에서는 답변 생성 부분만 건너뛰되 **건너뛴 이유를 명시 출력**(무폴백).
실행 로그를 리포트에 그대로 캡처한다(가공 없이).

3. #7(ingest 경로/확장자)의 위협모델이 정직한가 — docs_dir이 CLI 운영자 통제라 원격 공격자
   시나리오는 아니라는 점을 리포트에 명시해야 하는가.
4. 시연 스크립트가 실제 "결정론"과 "실모델 필요" 파트를 명확히 분리하는가.
