## 4. 아직 주장할 수 없는 것 (정직성)

- **감사 신호의 precision/recall** — 정답셋이 없다. 87.6%가 전부 실제 결함이라는 뜻이 **아니다.**
  실제로 부록 흡수 신호는 오늘 과탐이 드러나 11,478 → 4,789 로 줄었다.
- **전처리 개선이 검색 품질을 올린다는 것** — 잘못 크게 합쳐진 청크가 오히려 hit@k 를 높일 수 있다.
- **12개사 일반화** — 3rd 와의 비교는 4개사(공통 400문서) 범위다.
- **모델 선정(e5-large)** — s2 또는 3rd 청크 위에서 나온 값이다. s5 로는 재평가가 필요하다.
