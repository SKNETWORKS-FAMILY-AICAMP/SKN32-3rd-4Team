## 2. L1 — 정답셋이 66레코드·한 조판뿐

**원인**: 사람이 눈으로 확인한 것만 넣었고, 확장 비용이 커서 멈췄다.

**해결**
- [ ] L1-1 **층화 기준 확정** — (보험사 12) × (조판 세대) × (표 유형 4: 질병분류·장해분류·자기부담금·용어정의)
- [ ] L1-2 **후보 자동 추출** — `선` 경로 **고유 613개**(s5 페이지 기준 813개)에서 층별로 뽑아
      라벨링 대기열 생성
- [ ] L1-3 **라벨링 비용 절감** — 사람은 "맞다/틀리다"만 찍고, 셀 값은 추출 결과를 **수정**하는 방식.
      백지에서 타이핑하지 않는다
- [ ] L1-4 **최소 표본** — 층당 3표 × 12사 = 36표 목표. rule of three 로 층별 "오류율 63% 미만"까지밖에
      못 말하지만, **층이 무너지는 곳**은 3표로도 드러난다
- [ ] L1-5 확장 후 `clause_table_check` 재측정. **1.000 이 떨어지는 것이 정상이다** — 떨어지지 않으면 표본을 의심한다

**검증**: 층별 precision/recall 표. 층 하나라도 0.9 미만이면 그 층은 "미검증"으로 표시하고 판정에서 뺀다.

## 3. L2 — 무테두리 3열 이상 표가 2열 경로로 간다

**원인**: `find_two_col()` 은 **경계를 하나만** 찾는다. 3열이면 두 경계가 필요한데 구조상 못 만든다.

**해결**
- [ ] L2-1 경계를 **k개** 찾는 일반화 — 공백 통로(whitespace corridor)를 x 투영에서 **모두** 찾고,
      각 후보 조합을 `build_grid` 로 세워 점수로 고른다
- [ ] L2-2 열 수 k 결정 — k=1..5 를 다 세워 보고 **행별 셀 채움률**이 가장 고른 k 를 택한다
- [ ] L2-3 실측 3건(삼성생명 24~30행 → 7행)으로 회귀 테스트

**검증**: 그 3건이 24~30행으로 복원되는가. 정답셋 1.000 이 유지되는가.

## 4. L3 — 보장한도·자기부담금 표 (관계 구조)

**원인**: 이 표는 2차원이 아니라 **유형 × (입원/통원) × 기관종별** 3축이다.
평평한 `records` 로는 "상급종합병원 통원 자기부담금"을 못 집는다.

**해결**
- [ ] L3-1 **스키마 설계** — `coverage_limit` 레코드:
      `{급여구분, 입통원, 기관종별, 자기부담률, 한도금액, 통화, 단위, 근거_locator}`
- [ ] L3-2 헤더 계층 파싱 — 병합 헤더(rowspan/colspan)를 축 이름으로 승격
- [ ] L3-3 **값 정규화** — `20%`·`2만원`·`최소 1만원`을 구조화. ★파싱 실패는 **비워 둔다**(§1)
- [ ] L3-4 판정 경로 연결 — `precheck` 가 이 레코드를 읽어 금액을 답하게

**검증**: 자기부담금 정답셋 별도 구축(층당 2표). 금액·비율 정확 일치.

## 5. L4 — 2열짝짓기 과탐 (가장 크다)

**원인**: 점수 문턱 0.6 이 **표와 본문 두 단 조판을 못 가른다.**
실측 증거:
```
'6.' | '응급환자의 이송 등…'      ← 6·7·8행에 같은 값 반복
'보험금 ④ 회사는' | '늦어지는 경우 보험수익자…'
'실손의료비보험은 에 한정합니다)를' | '보험회사가 피보험자의 질병 또는…'
```
마지막 것은 **한 문장을 두 열로 쪼개며 어절이 뒤섞인 것**이다.

**해결 — 판별 신호를 쌓는다** (웹리서치 수렴점: 열 경계 정렬 일관성 + 공백 통로)
- [ ] L4-1 **공백 통로 무결성** — 경계 x 를 가로지르는 단어가 **0개**여야 한다.
      지금은 벌점만 준다. 표는 통로가 깨끗하고 본문은 제목 줄이 가로지른다
- [ ] L4-2 **좌열 우변 정렬 분산** — 표의 좌열은 짧고 들쭉날쭉,
      본문 두 단은 **오른쪽 정렬이 일정**(같은 여백까지 채움). 분산으로 가른다
- [ ] L4-3 **문장 신호** — 좌셀에 `①②③` 또는 문장 종결(`다.` `습니다.`)이 있으면 본문 쪽 가중
- [ ] L4-4 **연속 중복 셀** — 우셀이 연속 3행 이상 같으면 rowspan 오연결. **버린다**
- [ ] L4-5 **페이지 점유율** — 그 "표"가 페이지 단어의 대부분을 먹으면 본문이다
- [ ] L4-6 위 신호로 **판정기**를 만들고, 알려진 참(용어정의표 DB `02aaee47b190` p53,
      자기부담금 표)과 알려진 거짓(위 3건)으로 먼저 맞춘다
- [ ] L4-7 통과한 것만 `TRUSTED_TABLE_METHODS` 에 추가. **보류 수는 계속 센다**

**검증**: 알려진 참을 다 살리고 알려진 거짓을 다 버리는가. 그 뒤 무작위 30개 사람 판정.

## 6. L5 — 표 개수만 알고 정확도를 모른다

**원인**: 무참조 지표가 `word_coverage` 하나뿐이고, 그건 "단어가 셀에 다 들어갔나"만 본다.
본문을 표로 오인해도 1.0 이 나온다 — **실제로 그랬다.**

**해결 — 무참조 과탐 지표**
- [ ] L5-1 `T1 통로무결성` — 경계를 가로지르는 단어 비율 (0 이어야 함)
- [ ] L5-2 `T2 셀중복률` — 연속 동일 셀 비율
- [ ] L5-3 `T3 좌열길이 변동계수` — 표는 크고 본문은 작다
- [ ] L5-4 `T4 문장종결 비율` — 셀이 문장으로 끝나는 비율
- [ ] L5-5 `T5 어절파손` — 셀 경계에서 단어가 잘렸나 (사전 없이: 조사/어미로 시작하는 셀)
- [ ] L5-6 이 5개를 `stats.table_quality` 에 남기고, 임계값은 L4-6 판정기와 함께 정한다

**검증**: 알려진 참/거짓 집합에서 각 지표의 분리도(AUC 대용: 겹침 구간 크기)를 재고 기록한다.

## 7. 실행 순서 (의존성)

```
L4/L5 (판별 신호)  ──┬──> L1 (정답셋 확장)  ──> 층별 precision/recall
                     └──> L2 (3열 일반화)
L3 (자기부담금)  ← 독립. L1 뒤에 별도 정답셋
D1~D3 (정합·manifest·상태표)  ← 지금 바로 가능
```

**먼저 할 것**: D3(상태표) → L5(지표) → L4(판정기) → L1(정답셋) → L2 → L3

### ★여기서 배운 것 — **정답 없이 문턱을 맞추지 않는다**

T1 임계값을 **참 4 · 거짓 3** 으로 맞췄다. 그 표본에서는 깨끗이 갈려 보였다
(참 0.039 / 거짓 0.064). 전량에 적용했더니 통과한 4,607개 중 **3,685개(80.0%)** 가
본문이었다 — 경계 0.041~0.051 구간에 본문이 잔뜩 있었다.

L2 도 같은 함정 앞에 있다. 통로 검출은 고쳤지만(전폭 제목이 통로를 지우던 문제),
**열 수 k 를 옳게 고르는지 확인할 정답 케이스가 없다.** 그래서 파이프라인에 연결하지 않았다.

**L1 이 나머지 넷의 선행 조건이다.** 이제 순서가 분명하다.
