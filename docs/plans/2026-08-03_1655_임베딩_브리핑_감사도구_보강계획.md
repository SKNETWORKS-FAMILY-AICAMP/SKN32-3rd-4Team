# 임베딩 브리핑 감사 도구 보강 계획

작성 2026-08-03 16:55

## 목표

`scripts/eval/audit_brief.py`에 기록된 12개 감사 결함을 구현으로 보완하고,
정상 fixture와 단일 변조본(mutant)을 이용한 회귀시험으로 각 검사 경계를 고정한다.

## 범위

- 수정: `scripts/eval/audit_brief.py`
- 후속 수정: `scripts/eval/bench_embedders.py`
- 신설: `tests/test_audit_brief.py`
- 후속 신설: `tests/test_bench_embedders_cli.py`
- 종료 기록: 이 작업의 `docs/reports/` 리포트와 `docs/history/` 추가 항목
- 읽기 전용: 브리핑 문서, 동결 JSON, 평가셋·결과 JSON, 관련 생성 스크립트
- 제외: `app/core/domain/eligibility.py`, 브리핑 문서 내용, GPU 원격 작업

## 단계와 완료 기준

1. [완료] 동결 대조·범위, JSON 수집·스키마·지표 재계산, 생성 명령, 주장·본문 숫자,
   CP949 출력을 보강한다.
2. [완료] 각 검사에 정상본과 단일 변조본을 둔 단위시험을 작성한다.
3. [완료] 요청된 세 명령을 그대로 실행하고 원문 결과와 새로 드러난 문서 결함을 기록한다.
4. [완료] 작업 리포트를 제출하고 history에 추가한다.

## 후속 재개 (2026-08-03 17:53)

앞선 감사에서 도구 밖의 실제 결함과 시험 공백이 드러나 사용자 요청으로 이어서 처리한다.

5. [완료] `bench_embedders`의 report/prefix 출력 모드가 표를 출력한 뒤 `--model` 오류로
   종료하는 제어흐름 결함을 최소 수정한다.
6. [완료] 실제 CLI 디스패처 시험을 추가해 report·prefix·repro 출력 모드와 model 측정 모드를
   함께 고정한다. 감사기의 mock subprocess 시험만으로 완료 판정하지 않는다.
7. [완료] 독립 재감사에서 드러난 경계를 mutant로 닫는다: Markdown 셀·`<br>` 증거 태그,
   `blind_eps=None`, 생성 마커 누락, 현행 중첩 title 지표, 결과 파일명 포함 동결 해시,
   ranks 단독 누락, 종료코드/stderr 독립 검사, 실제 CP949 출력, tail 전후값.
   구두점 없는 자연어의 의미 문장 분리는 추측으로 만들지 않는다.
8. [완료] 집중 시험과 실제 감사 명령을 다시 실행한다. Qwen3-4B@4bit의 ranks 없는 구형 결과는
   GPU 재측정 없이 합성하지 않고 미해결 데이터 결함으로 유지한다.
9. [완료] 감사 실패가 남은 동안 `--freeze`를 실행하지 않는다. 후속 리포트와 history를 추가한다.

## 제약

- 오류를 폴백하거나 조용히 건너뛰지 않고 가능한 결함을 모두 수집한다.
- 구형 `Qwen/Qwen3-Embedding-4B@4bit` 결과가 정상 예외인지 실제 산출 경로로 확인한다.
- 기존 사용자·병행 트랙 변경은 보존한다.
