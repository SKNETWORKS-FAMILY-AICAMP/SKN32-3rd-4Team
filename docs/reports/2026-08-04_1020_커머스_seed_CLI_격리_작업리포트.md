팀원이 새 clone에서 README대로 `python -m scripts.manage seed`를 실행했을 때
누락된 `data/products.csv` 때문에 중단되는 문제를 수정한다. CSV를 활성 트리에 복원하지 않고,
커머스 시더와 호출자를 기존 레거시 보관 규칙대로 압축 격리한다.

## 4. 동작 계약

보험 프로젝트의 로컬 DB 준비 명령은 다음 하나다.

```powershell
python -m scripts.manage migrate
```

커머스 `seed`는 성공하는 빈 동작으로 남기지 않았다. 호출하면 제거된 명령으로 명시적으로 거부한다.
