## 1. 고객 스토어프론트
- 신규 `app/static/shop.html`/`shop.js` + style.css 확장:
  - 상품 그리드(카드: 분류 뱃지·그라디언트 썸네일·이름·코드·가격·재고·담기), 검색·분류 필터.
  - 장바구니 패널(수량 ±/삭제, 합계), 모바일 반응형(820px 이하 1열).
  - 주문 흐름: 담기 → 주문하기 → (미로그인 시 로그인/간편가입 모달, 얼굴 등록 계정은 공통
    `submitLogin`으로 웹캠 2차 인증) → **미리보기 모달**(재고·소계·합계·feasible) → **결제 승인**
    (`POST /api/orders` Idempotency-Key) → 주문번호 표시·장바구니 비움·재고 갱신.
  - 기존 커머스 백엔드(Phase 6: /api/products, /api/orders/preview, /api/orders) 그대로 사용 —
    이전엔 orders.html(개발 하네스, 버튼→JSON)만 있었는데 실제 고객이 쓰는 화면을 신설.
- 전 페이지 nav 첫 항목에 "🛍️ 쇼핑" 추가.

## 2. 상품명 옛 브랜드 잔재 정리 (스토어에서 발견)
쇼핑 화면 첫 캡처에서 상품명이 "**승승** 무선 블루투스…"로 나옴 — 리네이밍 때 "승승장구몰"만
바꾸고 시드 상품명의 "승승" 접두사(승승장구에서 파생)를 놓쳤음. 정밀 확인("승승 " 접두사만
존재, "승승장구" 텍스트 잔재 없음) 후:
- `data/products.csv`·`inventory.csv`·`orders.csv`의 "승승 "→"바로봄 " 교체(각 5/5/4곳).
- 라이브 `mall.db`도 인플레이스 교체(products 5행, order_items 8행) — 재마이그레이션 없이
  기존 계정·주문 보존.
- `tests/test_tools.py`의 상품검색 테스트 "승승"→"바로봄".
- `git grep 승승` 결과 코드·데이터·프론트 **0곳**(이력/리포트의 리네이밍 서술만 제외).
