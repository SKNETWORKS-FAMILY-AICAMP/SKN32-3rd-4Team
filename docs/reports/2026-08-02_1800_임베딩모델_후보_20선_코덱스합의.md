## ★0. 조사하다가 더 큰 것이 나왔다 — 지금 모델은 **128토큰에서 자른다**

코덱스가 "`jhgan/ko-sroberta-multitask` 의 공개 설정은 `max_seq_length=128`"이라고 지적했다.
믿기 어려워 **실제 임베딩 경로로 확인했다.**

```
>>> from app.rag.embeddings import get_embeddings
>>> get_embeddings()._client.max_seq_length
128
```

우리가 "512토큰 모델"로 알고 있던 것이 **128**이다.
448토큰 예산으로 청킹해 봐야 **뒤 3분의 2가 모델에 들어가지 않는다.**

### 실측 — 뒤 문장이 정말 무시되는가

```
A = "회사는 … 보상합니다." (128토큰을 넘김)
B = A + " 다만 고의로 자신을 해친 경우에는 보상하지 않습니다."

코사인 유사도 = 1.000000
```

**완전히 같은 벡터다.** 면책 문장을 붙였는데 임베딩이 조금도 안 움직였다.

> ★이게 왜 최악인가 — **면책 조항은 문장 끝에 온다.**
> "…보상합니다. **다만** … 경우에는 보상하지 않습니다."
> 우리 서비스가 절대 놓치면 안 되는 부분이 **구조적으로 검색에서 사라진다.**

### 손실 규모 (표본 969개 조항)

| | 값 |
|---|---|
| 조항 토큰 중앙값 | 186 |
| **128토큰 초과 조항** | **602개 (62%)** |
| **버려지는 토큰 비율** | **83%** |

앞서 내가 잡은 "800자 조각의 1.4%가 512토큰 초과"는 **틀린 진단은 아니지만 규모가 작았다.**
진짜 문제는 그 아래에 있었다. 코덱스가 아니었으면 못 봤다.

**→ 어느 모델을 고르든 지금보다 낫다.** 후보는 전부 512~32,768토큰이다.
이건 "성능 개선"이 아니라 **고장 수리**다.

## 6. `e5-large` 를 그대로 갈 것인가

### 먼저 — **모델 ID가 확정되지 않았다**

```
intfloat/e5-large             영어 중심 → 한국어 약관에 쓰면 안 된다
intfloat/multilingual-e5-large  560M · 1,024d · 512토큰 → 합리적 기준선
```

모델팀 문서에 `e5-large` 라고만 적혀 있다. **어느 쪽인지 먼저 확정해야 한다.**

### 교체 가치

| 대상 | 판단 |
|---|---|
| KoE5 로 교체 | **가치 낮음.** 원본 대비 개선이 확인되지 않았다 |
| KURE-v1 / arctic-ko 로 교체 | **검증 가치 높음.** 학습 근거가 더 직접적이다 |
| Qwen3-0.6B 로 교체 | 검증 가치 있으나 **한국어 법률 증거가 아직 부족**하다 |

전량 재색인이 GPU 14~47분이므로 후보 3개를 전부 색인해도 **42~141분**이다.
**비용이 의사결정을 막을 정도가 아니다.**

> ★그러나 **모델팀의 e5-large 선정은 80문항 기준이고, 2위와 1~2문항 차이로 검정을 안 했다**
> (`10_계약_모델_평가.md` §289). 그리고 그 평가는 **s2 또는 3rd 청크 위**에서 나왔다 —
> 지금 s5 + 토큰 청킹으로 바뀌었으므로 **분모가 다르다.**

### 결론

**200~500개 실손보험 질의로 재보기 전에는 아무것도 확정하지 않는다.**

측정할 것: Recall@10/20 · 근거 조항 정확 적중률 · **면책↔보장 유사조항 오탐률** ·
다른 약관 버전 유입 건수 · locator 정확도.

`multilingual-e5-large` 대비 유의미한 개선이 없으면 재색인·임계값 재보정을 감수할 이유가 없다.

## 7. 1,024d 채택 시 함께 바뀌는 것

```
app/adapters/pgvector_clause_index.py   _EMBED_DIM = 768 → 1024
                                        vector(768) 컬럼 · HNSW 인덱스 재생성
```

- 저장량: 168,600조각 기준 float32 raw **518MB → 691MB (+33%)**
- ★**거리 임계값을 재사용하면 안 된다.** 모델마다 cosine 분포가 다르다
- 2,048d(Nemotron-3) 면 1,382MB (+167%)

3. 후보 3개 + 기준선 2개를 **같은 질의 세트**로 비교
4. 이긴 것으로 전량 재색인

★**그 전에 전량 임베딩을 돌리지 않는다.** 지금 돌리면 그 시간이 통째로 버려진다.
