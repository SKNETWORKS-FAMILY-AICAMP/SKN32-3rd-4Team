# shadow48 원격 파일 검증 PowerShell 이스케이프 오류

- 시각: 2026-08-03 20:52 KST
- 위치: 로컬 PowerShell에서 구성한 `scp ...; ssh ... powershell -Command` 일괄 명령

## 재현

원격 PowerShell 변수 `$files`를 로컬 문자열 안에서 백틱으로 이스케이프한 뒤 덧셈식에 넣었다.
로컬 PowerShell 파서가 원격 명령 전달 전에 `` `$files.Count ``를 유효한 값 식으로 해석하지 못했다.

## 실제 영향

- 명령 전체가 파싱 단계에서 종료 코드 1로 중단됐다.
- 세미콜론 앞의 `scp`도 실행되지 않았으므로 원격 평가 파일은 전송되지 않았다.
- 로컬/원격 데이터 변경과 GPU 작업 시작은 없었다.

## 수정

- 전송과 검증을 별도 호출로 나눈다.
- 원격 검증은 변수·중첩 따옴표가 없는 `cmd /c dir` 또는 별도 고정 스크립트를 사용한다.
