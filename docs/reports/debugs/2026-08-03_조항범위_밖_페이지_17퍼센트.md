# 쪽의 **17.1%** 가 조항·부록 어디에도 안 덮인다

- 날짜: 2026-08-03
- 상태: **미수정.** 원인 미규명·범위 실측 완료
- 위험도: **중~높음** — 그 쪽의 표·본문이 판정에 **도달하지 않는다**
- 규칙: RULE.md §4.0

---

## 1. 어떻게 발견했나

사람 라벨 59건으로 표 게이트를 재던 중, `true` 로 라벨된 표 하나가
조항 JSON 에 안 실려 있었다. **T9(본문 모양) 게이트를 의심했는데 무죄였다** —
그 표의 신호는 `is_table=True · prose=False` 였다.

원인은 다른 데 있었다. **그 쪽을 덮는 조항이 하나도 없다.**

```
e05cbfdbdf6d  parse_status=ok · 조항 267 · 부록 9
  p25 를 덮는 조항/부록: 0
  전체 쪽 범위: 6 ~ 293
  toc_pages 에 25 있나: False
```

표는 `tables[].page` 로 붙는데, **조항의 `locator.page_from~page_to` 안에 없으면**
어느 조항에도 안 붙는다. 목차도 아니다 — 그냥 **비어 있다.**

## 2. 재현

```bash
export PYTHONIOENCODING=utf-8
python - <<'PY'
import json
from pathlib import Path
p = list(Path('data/structured').rglob('s6_pymupdf-1.28.0/e05cbfdbdf6d.clauses.json'))[0]
j = json.loads(p.read_text(encoding='utf-8'))
rng = [( (x.get('locator') or {}).get('page_from'), (x.get('locator') or {}).get('page_to') )
       for k in ('clauses', 'annexes') for x in (j.get(k) or [])]
print('p25 를 덮는 조항/부록:', sum(1 for a, b in rng if a and a <= 25 <= (b or a)))
print('toc_pages 에 25:', 25 in (j.get('toc_pages') or []))
PY
```

목차 페이지(`toc_pages`)는 **분모에서 뺐다.** 목차는 일부러 안 덮는다.

> ★표본 395문서다. 전량은 안 셌다.

## 4. 위험도

1. **그 쪽의 표가 판정에 안 온다.** 이번에 사람이 `true` 라 한 표 하나가 그래서 빠졌다.
2. **그 쪽의 본문도 안 온다.** 조항이 없으니 KCD 코드도 안 뽑힌다.
   면책 조항이 그 구간에 있으면 **"그런 조항이 없다"** 고 답한다 — 근거 없음이 아니라 **틀린 답**이다.
3. `parse_status="ok"` 인 문서에서 일어난다. 품질 지표가 이걸 못 본다.

## 5. 원인 후보 (미규명)

확인하지 못했다. 후보만 적는다.

- 조 머리를 못 찾은 구간 — 표지·안내문·부록 사이 여백 등
- 참조머리 필터(`_REF_TAIL`)가 진짜 머리를 지운 자리
- 부록 종료 경계가 짧게 끊긴 뒤 다음 조 머리까지의 사이
- 원래 조항이 없는 쪽(표지·백지·광고) — **이건 정상이다.** 얼마가 정상인지 모른다

★**17.1% 가 전부 결함이라는 뜻이 아니다.** 표지·백지가 얼마인지 안 셌다.
그걸 가르지 않고는 심각도를 말할 수 없다.
