# x600 OCR 디렉터리 생성 따옴표 오류

- 시각: 2026-08-03 19:15 KST
- 위치: 로컬 PowerShell에서 `ssh x600 powershell -Command ...` 호출
- 재현: 원격 `New-Item ... | Out-Null` 명령을 중첩 큰따옴표로 전달
- 증상: 원격에서 `Out-Null\`을 cmdlet 이름으로 해석하여 exit code 1
- 영향: 디렉터리 생성 명령만 실패했다. 모델 다운로드, GPU 추론, 입력 전송은 시작되지 않았다.
- 원인: 로컬 PowerShell, SSH, 원격 PowerShell의 3단계 인용에서 닫는 역슬래시/큰따옴표가 원격 토큰에 잔존했다.
- 조치: 중첩 인용을 반복하지 않고 별도 `.ps1` 파일을 전송해 실행한다.

## 추가 관찰

- 전송 후 해시 확인에서 `ssh x600 "Get-ChildItem ..."`도 exit code 1로 종료됐다.
- 원인은 x600의 SSH 기본 셸이 PowerShell이 아니라 `cmd.exe`인 점이다.
- 입력 SHA 검증은 실행기 자체가 각 이미지에 대해 수행하므로, 검증을 생략하지 않고 실행기 JSON에 남긴다. 이후 원격 명령은 모두 `.ps1` 파일로 전달한다.
