# agent_app 직접 기동 시 비활성 플래그 우회

- 발견일: 2026-08-04
- 대상: `app.agent_main:agent_app`, `scripts.run_agent_server`
- 상태: 수정 전 기록

## 현상

전용 실행 스크립트는 `AGENT_API_ENABLED=false`이면 기동을 거부하지만, Uvicorn 모듈 경로를
직접 지정하면 실행 스크립트를 거치지 않는다.

```bash
python -m uvicorn app.agent_main:agent_app --port 8082
```

이 경우 DB와 hash secret만 준비돼 있으면 비활성 플래그가 false여도 보호 endpoint가 요청을
처리할 수 있다. 설정 플래그가 실행 명령 선택에 따라 다른 의미가 된다.

## 수정 방향

실행 스크립트의 사전 검사와 별개로 canonical 인증 dependency에서도
`AGENT_API_ENABLED`를 검사한다. 따라서 어떤 ASGI 실행기를 사용해도 보호 endpoint는 503으로
fail-closed한다. 테스트는 활성/비활성 두 상태를 고정한다.
