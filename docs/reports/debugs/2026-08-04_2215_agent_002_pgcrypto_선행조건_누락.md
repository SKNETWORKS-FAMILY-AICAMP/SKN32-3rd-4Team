# agent 002 migration pgcrypto 선행조건 누락

- 발견일: 2026-08-04
- 재현: `python -m scripts.pg init-agent`
- 결과: `UndefinedFunction: function digest(text, unknown) does not exist`
- 부분 적용: 없음. `apply.py`의 DDL+ledger 단일 트랜잭션이 모두 롤백함

`002_agent_security_hardening.sql`이 기존 idempotency key를 일회성 SHA-256으로 이관하면서
`digest()`를 사용하지만 agent DB의 `001`은 pgcrypto를 만들지 않는다. 미적용 002 맨 앞에
`CREATE EXTENSION IF NOT EXISTS pgcrypto`를 추가한 뒤 재적용하고, 두 번째 실행이 skip인지 확인한다.
