# 임베딩을 멈췄다 — 모델이 **128토큰에서 자른다**, 그리고 모델을 고른 적이 없다

- 날짜: 2026-08-03
- 발견 경위: **사용자가 물었다** — *"임베딩은 왜 벌써 하고 있어? 뭘로 임베딩 할지도 안 정했는데?"*
- 조치: 로컬·GPU 양쪽 적재 **즉시 중단**. 이미 들어간 벡터는 지우지 않고 **표시해서 가둠**

---

## 1. 무엇이 잘못됐나

내가 s6 전처리를 끝내고 **곧바로 전량 임베딩을 걸었다.** 두 가지가 틀렸다.

### 1-1. 모델이 정해지지 않았다

`docs/reports/2026-08-02_1800_임베딩모델_후보_20선_코덱스합의.md` §결론:

> **200~500개 실손보험 질의로 재보기 전에는 아무것도 확정하지 않는다.**

**하루 전 우리 문서**다. 읽지 않고 기본 설정값으로 5시간짜리 작업을 시작했다.

### 1-2. 그 기본값은 **고장 난 모델**이다

같은 문서 §0 제목이 「지금 모델은 **128토큰에서 자른다**」이다.

```
>>> SentenceTransformer('jhgan/ko-sroberta-multitask').max_seq_length
128
```

우리 청킹 예산은 **448토큰**이다. 뒤가 모델에 들어가지 않는다.

---

## 2. 실측 — 얼마나 버려졌나

중단 시점에 GPU 로 보낸 샤드에서 **6,000조각**을 다시 세었다.

| | 값 |
|---|---:|
| 조각 토큰 중앙값 | 358 |
| 조각 토큰 평균 | 305 |
| 90분위 | 392 |
| **128토큰 초과 조각** | **5,347 (89.1%)** |
| **버려진 토큰** | **1,093,752 / 1,828,974 = 59.8%** |

### 왜 이게 최악인가

면책은 **문장 끝**에 온다.

> "…보상합니다. **다만** … 경우에는 보상하지 않습니다"

앞 128토큰만 임베딩하면 **면책 문장이 벡터에 반영되지 않는다.**
어제 리포트의 실측: 면책 문장을 붙인 텍스트와 안 붙인 텍스트의 코사인 유사도 **1.000000** —
완전히 같은 벡터다. 우리 서비스가 절대 놓치면 안 되는 부분이 **구조적으로 검색에서 사라진다.**

---

## 3. 조치 — 지우지 않고 가둔다

`policy_clause_chunk` 에 `embed_model` 열을 넣고 검색이 **현재 모델의 벡터만** 보게 했다.
발생행에 `index_generation` 을 넣은 것과 같은 방식이다.

```
by_embed_model:
  jhgan/ko-sroberta-multitask@128 : chunks 46,385 · contents 14,239   ← 격리됨
current_embed_model               : (설정값 · 아직 미확정)
```

### 여기서도 PK 함정을 막았다

`upsert_chunks` 는 `ON CONFLICT DO NOTHING` 이다. `embed_model` 이 PK 밖이면
새 모델 벡터가 **버려지고** 옛 벡터가 자리를 지킨다 — 로그에는 "이미 있음"으로 찍힌다.
PK 를 `(content_hash, chunk_ix, embed_model)` 로 바꿨다.
`existing_hashes` 와 `drop_incomplete` 도 **모델 안에서만** 판단하게 고쳤다.

### 모델 ID 를 코드에 적지 않았다

처음엔 상수로 박았는데 `tests/test_model_registry.py::test_llm_reg_002` 가 잡았다.
하드코딩하면 설정을 바꿔도 태그가 안 따라와 **벡터 공간이 조용히 섞인다.**
`current_embed_model()` 이 레지스트리(설정)에서 읽도록 바꿨다.

## 4. 낭비된 것과 남은 것

| | |
|---|---|
| 버린 계산 | 조각 약 46,000개 분량 (로컬 CPU 약 80분 + GPU 약 25분) |
| 남은 것 | 발생행 195,617(s6) · 조항 JSON s6 전량 — **재사용 가능** |
| 남은 것 | 분산 적재 장치(`shard_embed.py` · `gpu_embed.py`) — 모델만 바꿔 끼우면 된다 |

GPU 상자에 torch+CUDA 를 깔아 둔 것도 남는다(`cuda True`, RTX 4070 SUPER).

## 6. 배운 것

**"전처리가 끝났으니 임베딩"은 순서가 아니다.** 임베딩은 모델 선택에 종속된다.
그리고 그 선택은 **이미 문서로 남아 있었다** — 내가 안 읽었을 뿐이다.

작업을 시작하기 전에 `docs/reports/` 에서 그 주제의 최신 문서를 먼저 읽는다.
