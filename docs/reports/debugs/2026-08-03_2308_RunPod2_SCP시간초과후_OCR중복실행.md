# RunPod 2 SCP 시간초과 후 OCR 중복 실행

- 발견: 2026-08-03 23:08 KST
- 위치: RunPod 2 초기 패킷 전송·smoke 원격 명령
- 위험도: 높음 — 같은 JSON 경로에 두 프로세스가 동시에 쓸 수 있음

## 실측

- 첫 호출은 로컬에서 124초 timeout이었지만 원격 명령은 계속 진행
- 재시도 후 PID 2607·2747이 동일 `output/runpod_smoke10`으로 실행

## 원인

SSH/SCP 클라이언트 timeout을 원격 명령 실패로 간주하고 원격 PID를 확인하지 않은 채 재시도했다.

## 수정

- 먼저 시작된 PID 2607 유지, 최신 중복 PID 2747 종료
- 이후 재시작 전 `pgrep`뿐 아니라 출력 디렉터리까지 대조
- production batch는 장비별 고유 출력 디렉터리를 사용
