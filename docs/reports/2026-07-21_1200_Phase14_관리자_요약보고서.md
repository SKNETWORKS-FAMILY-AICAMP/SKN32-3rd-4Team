# Phase 14 — 관리자 대시보드 요약 보고서 생성/저장/인쇄

- 작성일시: 2026-07-21 12:00
- 계기: `프로젝트설명.txt` [추가 서비스 제안] 6번(관리자 대시보드 요약 보고서 생성/저장/인쇄).
  추가 서비스 제안 6개 중 마지막 항목 — 이로써 6개 전부 구현 완료.

## 1. 구현
- `app/services/admin_report.py`:
  - `build_admin_report_pdf(db)`: 대시보드와 동일한 요약 데이터(준비상태·주문 총건수/상태별/
    총결제금액·이벤트 총건수/종류별 상위8·지식갭 미해결/전체)를 모아 reportlab로 PDF 생성.
    한글은 맑은 고딕 임베딩, 폰트 없으면 ConfigError(무폴백 — 깨진 글자 방지).
  - `save_admin_report(db)`: `generated_reports/`(gitignore)에 타임스탬프 파일로 서버 보관.
- `app/routers/admin.py` `GET /api/admin/report`: 서버 저장 + 같은 PDF를 다운로드 응답
  (application/pdf, Content-Disposition attachment). 라우터 전역 `require_admin`으로 보호.
- 프론트 `admin.html`/`admin.js`: 헤더에 "📄 보고서 PDF"(다운로드) + "🖨 인쇄" 버튼.
  인쇄는 `@media print` CSS로 네비/로그인/버튼/필터를 숨기고 대시보드 데이터만 깔끔히 →
  `window.print()`. 다운로드는 fetch(authHeaders) → blob → a[download].

## 2. 검증
- PDF 생성 스크립트 확인: 55KB, 4개 섹션(준비상태·주문 6건/948,000원·이벤트 14건 rag_query·
  지식갭 0/0)·브랜드 "바로봄" 포함, PNG 렌더로 한글·표 정상 확인.
- 실 브라우저(관리자 로그인): `GET /api/admin/report` 200·application/pdf·`%PDF` 매직·
  attachment 파일명 확인. 보고서/인쇄 버튼 존재. 서버 `generated_reports/`에 스냅샷 저장 확인.
- `pytest tests/test_rbac_admin.py tests/test_ui.py` 37 passed(보고서 401/403/200[또는 폰트
  없으면 503] 견고 테스트 추가, admin.js에 /api/admin/report 검사 추가). 전체 회귀 325 passed.

## 3. 한계(정직)
- 한글 폰트(맑은 고딕)는 Windows 경로 하드코딩 — 비Windows에선 ConfigError(503). 테스트는
  503도 허용하도록 견고하게 작성. 필요 시 폰트 경로를 config로 뺄 수 있음(후속).
- 인쇄 레이아웃(@media print)은 프린트 다이얼로그라 자동 시각검증은 못 함(CSS 규칙으로 네비·
  버튼 숨김 처리). 보고서 PDF는 렌더 이미지로 검증함.
- 보고서는 "생성 시점 스냅샷"(문서에 명시). 서버 저장분은 gitignore.
