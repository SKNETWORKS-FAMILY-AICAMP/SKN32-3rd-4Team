# v3.2 방향 전환 리포트 (학습·포트폴리오 중심)

- 작성일시: 2026-07-19 16:00
- 계기: 사용자 지적 — "난 포스트그래스에 pg백터에 그래프DB까지 쓰는 걸 연습하고 싶은데? 이건 반영된 부분 있어?"

## 1. 문제 진단 (정직)
v3.1은 Codex 고도화를 따라 **PostgreSQL·pgvector·Hybrid·Rerank를 "후속(범위 밖)"으로 강등**했다.
그 근거는 "기존 SQLite+FAISS 재사용 + YAGNI + 하드웨어 제약"이었으나, **사용자의 진짜 목표는 이 스택들을
연습·구현하는 것**(포트폴리오, 넓게)이었다. 즉 최적화 기준(리스크 최소·기존자산 재사용)이 목표(학습 breadth)와
정반대였다. GraphRAG는 v3.0·v3.1 모두에 없었다.

## 2. 사용자 확정 방향 (AskUserQuestion)
1. 관계형/벡터: **SQLite/FAISS 기준선 유지 + PostgreSQL/pgvector 학습 트랙 병행**(포트 뒤 교체·비교).
2. 그래프DB: **GraphRAG 용도부터 설계** 후 DB 결정(Apache AGE vs Neo4j, 미정).
3. 우선순위: **기술 연습·포트폴리오(넓게)**.

## 3. 현행 상태 답변 (코드 확인 기반)
- **pg/pgvector/graphDB**: 반영 안 됨(오히려 후속으로 제외됨). → v3.2에서 MUST 학습 트랙으로 복원.
- **RAG 설계**: 단일 FAISS 파이프라인(청킹→ko-sroberta→FAISS→거리필터→출처인용 QA→abstention).
  Hybrid/Rerank/pgvector/GraphRAG 없음. (`app/rag/{qa,service,build_index}.py`)
- **ReAct**: 주 에이전트로 실사용(`app/agent/react.py`, `/api/agent/chat`, 수동 루프+도구+RAG검색).
- **CoT/Planning**: 코드·테스트로 원리만 보존, **라우터 미연결(실사용 안 함)**. (`templates.py` build_cot_prompt,
  `planning.py` make_plan — test_prompts/test_planning에서만) → v3.2에서 활성화.

## 4. 수행: v3.2 개정 계획서 작성
`plans/2026-07-19_1600_v3.2_학습중심_개정.md`:
- 목표 전환(넓게), 범위 재조정표(pgvector·Hybrid·Rerank·GraphRAG·CoT → MUST/학습 트랙).
- ADR-005'(병행 트랙·포트 교체), ADR-007(GraphRAG 설계 우선→DB 게이트), ADR-008(CoT/Planning 활성화).
- Phase 재설계(0~10): 포트(P1)→품질(P2)→**pgvector(P3)**→**Hybrid/Rerank(P4)**→**GraphRAG 설계/구현(P5a/5b)**
  →커머스승인(P6)→에이전트+CoT(P7)→MCP(P8)→관리자(P9)→안정화·시연(P10).
- 유지: RULE·모델registry·무폴백·phased·Codex gate·닫힌 루프. 후속 유지: 음성/화상/Passkey/풀바운티/4모델라우터.

## 5. 검증 / 다음
- 세 질문 답변은 **실제 코드 확인** 기반(RULE 1.1): `app/rag/*`(단일 FAISS), `app/agent/react.py`(ReAct 실사용),
  `templates.py`/`planning.py`(CoT·Planning 라우터 미연결=테스트만). 근거 있음.
- 계획 정합 Codex 검증: **v3.2 Codex 리뷰 2회 시도했으나 둘 다 최종 판정 전에 중단**(web search 시도가
  샌드박스 무네트워크로 실패 / 출력 스트림 절단). 정직하게: **Codex의 v3.2 "착수 가능" 판정은 받지 못했다.**
  대신 Codex가 리뷰 도입부에서 명시한 **점검 포인트 3가지를 선제 반영**했다:
  1. RetrieverPort 중립성 → ADR-005'에 포트 계약(`Evidence` 정규화 점수, 백엔드 필드 비노출) 명시.
  2. GraphRAG 근거 provenance → ADR-007에 그래프 근거의 원천 문서 역추적·출처인용 규정.
  3. CoT 자기검증 실패 시 동작 → ADR-008에 무폴백(무근거 반환 금지→abstention/재검색) 규정.
- 참고: v3.2는 **Codex가 3라운드 검증한 v3.1을 기반**으로 하며, 델타(범위 복원·GraphRAG·CoT)는 사용자 확정 방향이다.
- 다음: **Phase 1 착수**(RAG 수직 슬라이스 + `RetrieverPort`/`ModelGateway`/`AnswerQuestion` + fakes + `model_registry.yaml`).
  Phase 1 구현 전 Codex 리뷰를 (네트워크 없이) 다시 시도하거나, 구현 후 검증으로 대체한다.
