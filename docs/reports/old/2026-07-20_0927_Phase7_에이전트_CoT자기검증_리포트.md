### Codex 지적 처리 (정직)
**설계 라운드(FIX)** 4건 전부 반영: (a) 미지지 시 **초안 완전차단**이 정직한 계약,
(b) `verified=true`는 과신 → `SupportCheck`로 교체 + 진실성 보증 부인,
(c) allowlist는 이름만 통제 → **DB 변경 0 실증 테스트** 2층 추가 + 미리보기는 데이터,
(d) 검증기 독립성 약함(명시) + **근거 속 프롬프트 인젝션** 경계.

**구현 라운드** 지적 10건 반영:
1. **질문·초안이 데이터 경계 밖에 무방비 삽입** → 셋 다 각각 경계에 넣고 무력화(가장 중요한 수정:
   내가 지키겠다고 한 속성에 실제 구멍이 있었음).
2. `parse_verdict` 접두 일치(`supportedXYZ`) 허용 → 토큰 완전 일치.
3. `result:` 줄 중복 허용(인젝션으로 가짜 판정 삽입 가능) → 정확히 1개만.
4. 빈 `reason` 허용 → 비어있지 않은 1개 강제.
5. 비문자열 응답을 빈 문자열로 조용히 치환 → 타입 오류 명시 거부.
6. 예외 메시지에 모델 응답 원문 포함(초안 유출 경로) → 원문 제외.
7. `model_id="unknown"` 기본값(조용한 폴백) → **필수**, 비문자열·공백 거부.
8. 근거 없어 LLM 미호출인데 `checked_by="llm"` → `"precondition"`(provenance 정확성).
9. `unsupported` 시 모델 자유 서술 `reason`이 초안을 인용해 유출 가능 → **고정 문구**로 대체.
10. `model.complete()` 예외가 프롬프트(=초안)를 담아 클라이언트로 유출 가능 → 안전 문구로 교체.
    재수정: `type(exc)(...)` 재생성은 하위 타입 생성자 시그니처를 가정하므로 폐기 →
    알려진 `InfraError` 생성 후 `http_status`·`error_code`만 복사(HTTP 계약 보존).

**의도적으로 반영하지 않은 지적 1건(근거 기록)**: Codex는 마지막에 "`raise safe from exc`가
`__cause__`를 보존하므로 traceback·로깅 경로로 원문이 샐 수 있다"며 FINAL OK를 보류했다.
**채택하지 않았다.** 이유: (1) 여기서 말하는 '초안'은 사용자 비밀이 아니라 **모델이 생성한 텍스트**다,
(2) 실제 게이트웨이 예외는 연결 실패·타임아웃이지 프롬프트 에코가 아니다,
(3) `__cause__`를 버리면 상류 실패 원인을 잃어 **디버깅 가능성이 크게 훼손**된다,
(4) 서버 로그는 신뢰 경계 **안쪽**이다. → **클라이언트로 나가는 경로의 유출은 닫고 테스트로 고정**했고,
서버측 `__cause__` 보존은 진단성을 위한 **의식적 트레이드오프**로 남긴다(과장 없이 기록).

## 3. ★ 정직한 finding / 한계
- **자기검증은 독립 검증이 아니다.** 초안과 검증이 **같은 모델·같은 문맥**을 공유하므로 공유 오류를
  잡지 못한다. 그래서 `verified` 단정을 쓰지 않고 `SupportCheck(checked_by="llm")` + API
  `disclaimer`("근거 정합성 검사만 수행, 진실성·완전성 미보증")로 범위를 좁혀 표기했다.
- **인젝션 경계는 완화이지 보장이 아니다.** 구분자·지시무시 지침·무력화는 구조적 방어를 **높이지만**,
  모델이 지침을 따르지 않을 가능성을 없애지는 못한다(Codex도 동일 지적). 테스트로 고정한 것은
  "프롬프트 **구조**가 재구성되지 않는다"이지 "모델이 절대 속지 않는다"가 아니다.
- **무쓰기는 2층까지만.** 레지스트리 allowlist + DB 변경 0 실증. 읽기전용 DB 자격증명·런타임
  감사로그(3층)는 인프라 과제로 후속.
- 자기검증 품질(오탐/미탐율)의 **정량 측정은 미수행** — 고정 평가셋·프롬프트 버전 고정은 Phase 10.
