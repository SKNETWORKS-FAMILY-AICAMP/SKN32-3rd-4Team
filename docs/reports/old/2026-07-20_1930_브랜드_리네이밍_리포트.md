## 1. 단일 소스 변수화 (핵심 요구사항)
브랜드명을 두 곳의 단일 소스로 만들어, 이후 이름을 바꾸려면 각 계층에서 한 줄만 고치면 되게 했다:
- **백엔드**: `app/core/config.py`의 `BRAND_NAME = "옛 브랜드명"`. 모든 프롬프트·API 타이틀이 참조.
- **프론트엔드**: `app/static/common.js`의 `const BRAND_NAME = "옛 브랜드명"` + `applyBrand()`.
  타이틀의 `{{BRAND}}` 토큰과 `[data-brand]` 요소에 로드 시 주입.

(정적 HTML은 서버 템플릿이 아니라 백엔드 config를 직접 못 읽으므로, 계층별로 소스가 하나씩
있는 게 자연스럽다 — 각 파일 상단 주석에 서로를 가리키게 표시.)

### 백엔드 참조 전환
- `app/agent/react.py` `DEFAULT_SYSTEM_PROMPT` — f-string으로 `get_settings().BRAND_NAME` 참조.
- `app/prompts/templates.py` `HARDENED_ROLE` — 동일.
- `app/mcp/server.py` `grounded_rag_prompt` — 함수 내 지연 import로 참조.
- `app/application/answer_question.py` `_build_prompt` — 함수 내 지연 import. config는 프레임워크가
  아니라 core 설정이므로 TEST-ARCH-001(fastapi/langchain/sqlalchemy/openai 금지) 위반 아님(테스트 통과 확인).
- `app/main.py` FastAPI `title` — `get_settings().BRAND_NAME` 참조.

## 3. RAG 소스 PDF 재생성 (누출 방지)
`data/docs/환불교환정책.pdf`(git 추적)에 옛 몰이름 2곳 + 옛 법인명(주식회사·영문 상호)이 있었다. 이 PDF는 벡터스토어에 임베딩되므로, 안 고치면 **RAG 답변에 옛 브랜드가
누출**된다. `scripts/gen_policy_pdf.py`(reportlab, 맑은고딕 임베딩)로 재생성:
- 브랜드/법인명만 교체("(주)옛 브랜드명 / BAROBOM COMMERCE"), **사실(기간·배송비·조항·전화·문서번호)은
  전부 보존** — RAG eval이 의존하므로 숫자·기간을 그대로 유지(재생성 후 텍스트 추출로 7일/30일/
  6,000원/13,000원/1588-0000/CS-POL-2026-014/카드사 3~5일 전부 확인).
- 법인명까지 바꾼 건 합성 데모 문서의 리브랜딩 일관성 때문 — 원치 않으면 되돌릴 수 있음.
- 브랜드 변경 시 재현 가능하도록 일회성 스크립트가 아니라 `scripts/gen_policy_pdf.py`로 남김
  (config BRAND_NAME을 읽어 재생성).
- `python -m scripts.manage ingest`로 FAISS 인덱스 재빌드 → index.pkl에서 승승장구 0 / 옛 브랜드명 5,
  정책 사실(청약철회·6,000원) 포함 확인. (index.pkl·pgdata는 gitignore된 재생성 아티팩트.)

## 5. 사용자 질문 답변 — 사용자 화면 vs 관리자 대시보드 분리
"txt 파일처럼 분리되어 있는 거 맞지?" → **맞다.**
- 관리자: `admin.html`(별도 URL·파일). 백엔드 RBAC(`require_admin`, 401→403→200) + 프론트 게이트
  (미로그인 시 대시보드 본문 숨김)로 이중 보호.
- 고객: `index.html`(채팅)·`rag.html`·`orders.html`·`mcp.html` — 관리자 인증 없는 별도 파일.
- 단, 정직한 유보: 고객 페이지들은 아직 데모/테스트 하네스 스타일(버튼→JSON 표시)이지 세련된
  스토어프론트 UI는 아님 — 이전에 "고객 화면"으로 열어둔 과제와 동일(별개 후속).
