# 얼굴 로그인 강화 — 인식 백엔드 벤치마크 페이지 + 공통 2FA + 다중얼굴 앞사람

- 작성일시: 2026-07-21 10:00
- 계기: 사용자 요청 4건 — (1) 3개 인식 백엔드 로그인 성능 실측 HTML, (2) admin 로그인 2FA 연동,
  (3) 관리자 얼굴 등록 유도, (4) 모든 로그인 공통 적용. + 직전 "여러 명이면 앞사람 인식".

## 1. 다중 얼굴 → 앞사람 선택 (이미 커밋)
`_detect_single_face`(복수 시 거부) → `_detect_primary_face`(bbox 면적 최대=가장 앞 사람 선택).
그룹사진 6명에서 최대 면적 얼굴 정확히 선택 확인.

## 2. 인식 백엔드 성능 비교 페이지
- 백엔드: `POST /api/face/benchmark`(image_a, image_b) — **같은 정렬 crop**에 insightface/adaface/
  lvface 각각 임베딩→코사인·지연(ms)·매칭판정을 실측 반환(모델 부재는 error로 표시, 무폴백).
  `face.py`에 `benchmark_pair()` + `_embed(aligned, backend)`(백엔드 인자화) 추가.
- 페이지 `facebench.html`/`facebench.js`: A(기준)·B(비교) 얼굴을 웹캠 촬영 또는 파일 업로드 →
  실행 → 3백엔드 결과 표(코사인·판정·지연, 최고 코사인 🏆·현재 사용 백엔드 ⭐ 강조).
- 실측 확인(스크립트): 동일인 adaface 0.99/lvface 0.976/insightface 0.985 전부 매칭, 타인 전부 ~0
  거부. 엔드포인트 배선 브라우저 확인(빈 이미지 → 422 얼굴미감지).

## 3. 공통 2FA 로그인 헬퍼 (모든 로그인 공통 적용)
- `common.js`에 `submitLogin(username,password)` + `_face2faOverlay(challenge)` 추가:
  `/auth/login` 호출 → 얼굴 등록 계정이면 **웹캠 오버레이**로 촬영→`/auth/login/face`까지 마치고
  최종 토큰 반환. 미등록이면 바로 토큰. 실패/취소 시 토큰 없이 throw(무폴백).
- 이 헬퍼 하나로 어느 페이지 로그인이든 2차 인증이 일관 적용됨. 오버레이 CSS는 style.css.

## 4. admin/orders 로그인 2FA 연동 + 관리자 얼굴 등록 유도
- `admin.js` `handleLogin`이 `submitLogin` 사용 → 관리자도 얼굴 등록 시 웹캠 2차 인증. 로그인 후
  `maybePromptFaceEnroll()`이 `/api/face/status`로 미등록이면 "마이페이지에서 얼굴 등록" 안내
  배너를 로그인 상태줄에 표시(무강제 유도).
- `orders.js`의 기존-계정 로그인 경로도 `submitLogin` 사용.
- `mypage.html`은 기존 자체 2FA 흐름 유지(전용 얼굴 페이지).
