## 1. 구현
- 신규 `app/static/video.html` + `video.js`:
  - 좌: 고객 웹캠(`getUserMedia`), 우: AI 아바타(SVG 얼굴, TTS 재생 중 입 애니메이션).
  - 마이크 버튼 → 기존 `/api/voice/stt` → 기존 `/api/agent/chat` → 응답을 `/api/voice/tts`로
    재생하며 그때 아바타가 "말하는 중". **STT/TTS/녹음 헬퍼는 Phase 11의 common.js 재사용**
    (createVoiceRecorder, synthesizeAndPlay) — 음성 파이프라인을 새로 만들지 않음.
- `app/static/common.js` `synthesizeAndPlay(text, hooks)` 확장(하위호환): `onSpeakStart/
  onSpeakEnd` 훅으로 아바타 동기화, 새 발화 전 이전 발화 중단(`stopCurrentTts`, 중복 재생 방지).
- 전 페이지 nav에 "🎥 화상 상담" 링크 추가(index/rag/orders/mcp/admin/video 6개).
- 정적 파일이라 `/static` 마운트로 자동 서빙 — main.py 변경 불필요.

## 2. Codex 짧은 컨설트 반영 (model_reasoning_effort=low)
- **아바타-오디오 동기화**: `synthesizeAndPlay()` 호출 직후가 아니라 실제 `playing` 이벤트에서
  애니메이션 시작하고 `ended/pause/error/abort` 모든 경로에서 해제(구현대로).
- **무폴백**: 카메라 권한 거부를 조용히 텍스트모드로 넘기지 않음 — `NotAllowedError`(거부)/
  `NotFoundError`(장치없음)/`NotReadableError`(사용중)를 **사유별로 구분 안내** + "카메라 없이
  텍스트로 계속" 명시 버튼.
- **상태 분리·중복 방지**: 녹음/전송/응답/재생 중 `busy` 플래그로 중복 요청 차단, 새 응답 전
  기존 TTS 중단.
- **AI 명시**: 상단에 "상대는 AI 상담원(실제 사람 아님), 실제 영상통화 아님" disclaimer.
- **스트림 정리**: `pagehide` + 카메라 끄기 버튼에서 `getTracks().forEach(stop)` + `srcObject=
  null`, 재시작 시 기존 스트림부터 정리, `track.onended`로 외부 해제도 UI 반영.
