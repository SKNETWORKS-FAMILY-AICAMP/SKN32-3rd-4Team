## 0. 당신이 만드는 것

**확정된 약관 버전 안에서** 질문에 맞는 조항을 찾아 근거 묶음으로 내놓는다.

판정하지 않는다. 설명문도 쓰지 않는다. **근거를 고르는 것까지**가 당신 몫이다.

---

## 1. 제공할 함수

```python
# app/insurance/retrieval.py
def retrieve(
    *,
    policy_version_sha: str,       # policy_version.resolve() 가 확정한 문서
    kcd_codes: list[str],
    question: str | None = None,
    top_k: int = 8,
) -> EvidenceBundleV1:
    """확정된 약관 버전 안에서만 근거를 찾는다."""
```

### 반환 형태

```python
@dataclass(frozen=True)
class EvidenceBundleV1:
    policy_version_sha: str
    clauses: list[Clause]              # app.insurance.clause_store.Clause
    code_rules: list[CodeMention]      # app.insurance.kcd.CodeMention
    #: 준용을 따라간 경로. 못 따라간 것도 남긴다.
    reference_paths: list[ReferencePath]
    unresolved_references: list[str]
    #: 검색 방식·버전. 재현에 필요하다.
    retriever_version: str
    #: 조용히 자른 것이 있으면 여기 적는다.
    truncated: list[str]
```

## 2. 지켜야 할 경계

| 하면 안 되는 것 | 왜 |
|---|---|
| **다른 약관 버전 조항을 섞기** | 2019년 가입자에게 2024년 조항이 근거로 붙는다 |
| 판정문·설명문 생성 | 그건 AI 2 몫이다. 섞이면 근거와 해석이 구분되지 않는다 |
| `parse_status != "ok"` 문서 사용 | 조항 경계를 못 믿는 문서다 |
| `chunk_type == "page_fallback"` 청크 인용 | 조항이 아니라 페이지 덩어리다. "제N조"를 댈 수 없다 |
| 결과가 없을 때 비슷한 것 끌어오기 | **빈 목록을 돌려준다.** 근거 없음이 정답인 경우가 있다 |
| 자른 것을 조용히 버리기 | `truncated` 에 남긴다 |

## 3. 이미 있는 것 (그대로 쓰면 된다)

```python
from app.insurance import clause_store

clause_store.load_clauses(sha)            # 판정 가능한 조항만
clause_store.find_by_number(sha, "제9조")  # 같은 번호가 여럿이면 전부 준다
clause_store.search(sha, "보험금 지급")     # 낱말 포함 검색(임베딩 아직 없음)
clause_store.stats(sha)                   # parse_status 등
```

**당신이 채울 곳은 셋이다.**

1. **임베딩 검색** — 지금은 낱말 포함만 한다. `pgvector` 를 붙인다
2. **준용 해소** — 참조 185,061개 중 **52.6%가 모호**하고 9.9%가 문서 밖이다. 아직 안 따라간다
3. **검색 평가** — recall@k 를 잴 수 있게 만든다

---

## 4. 준용 해소 — 가장 중요한 일

**v4 전량 실측**(1,367문서, 조 머리 제외): 조항 간 상호참조 **185,061개**.

| 구분 | 건수 | 비율 |
|---|---:|---:|
| 같은 부에서 **유일하게 해소** | 69,512 | 37.6% |
| ★번호가 여럿 — **모호** | **97,273** | **52.6%** |
| 문서 안에 대상 없음(외부) | 18,276 | 9.9% |

★**절반 이상은 대상을 특정할 수 없다.** `"보통약관"`·`"특별약관"` 수식어가 붙은 참조는
**4,372건(2.4%)뿐**이고 나머지는 그냥 `"제9조"` 라고만 쓴다.
**따라갈 수 있는 것은 37.6%다** — 이 분모를 함께 말한다. 모호한 것은 **따라가지 않고 기권**한다.

> ⚠ 이전 판의 `72,099개 · 2/3이 문서 밖` 은 **v3·표본 400문서**이고 측정 정의도 달랐다.

```
제1조(자기부담금) 회사는 보통약관에서 정한 손해가 발생하는 경우
손해액에서 1사고당 (     )을 빼고 보통약관 제9조(지급보험금의 계산)에 따라
손해를 보상하여 드립니다.
```

**이 특약만 읽으면 자기부담금을 알 수 없다.** 괄호가 비어 있다.

### 제약

- 순회 깊이 **3단까지**
- **같은 `policy_version` 안에서만** 따라간다. 다른 시점으로 넘어가면 안 된다
- 못 따라간 것은 `unresolved_references` 에 남긴다 — 조용히 버리지 않는다

## 5. 검증 방법

```python
def test_다른_버전_조항이_섞이지_않는다():
    b = retrieve(policy_version_sha=SHA_2019, kcd_codes=["F32"])
    assert all(c.sha256 == SHA_2019 for c in b.clauses)

def test_근거가_없으면_빈_목록이다():
    b = retrieve(policy_version_sha=SHA, kcd_codes=["Z99"], question="존재하지않는낱말")
    assert b.clauses == []
```

골든 세트 20~30건은 AI 2와 함께 만든다.
