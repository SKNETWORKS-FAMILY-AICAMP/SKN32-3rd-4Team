## 0. 당신이 만드는 것

데이터가 앉을 자리와, 그것이 새지 않게 하는 장치.

---

## 1. DDL — [02_ERD_및_스키마.md](02_ERD_및_스키마.md) 참조

핵심 셋만 다시 적는다.

```sql
canonical_clause    content_hash PK · body · embedding vector(1536)
clause_occurrence   document_id + qualified_no + page_from  ← 인용이 가리키는 곳
clause_code_rule    content_hash + code 범위 + kind(exclude/exception/mention)
```

**임베딩은 canonical 에 한 번만.** 조항의 75%가 중복이라 그대로 넣으면 4배가 된다.

---

## 2. 적재 파이프라인

```
data/structured/*/s4_*/*.clauses.json
        ↓  scripts/db/load_clauses.py   ← 당신이 만든다
canonical_clause + clause_occurrence + clause_code_rule
```

### 지켜야 할 것

| 항목 | 규칙 |
|---|---|
| 멱등성 | 같은 파일을 두 번 넣어도 행이 늘지 않는다 |
| `excluded_reason` 있는 문서 | **적재하지 않는다** |
| `parse_status != "ok"` | 적재하되 **플래그를 남긴다**. 판정 쿼리에서 뺀다 |
| 실패 | 세어서 보고한다. `except: continue` 금지 |

## 3. API 상태 코드 — **이 구분이 무너지면 안 된다**

| 코드 | 의미 |
|---|---|
| **200** | 판정했다. `verdict="unknown"` 이어도 200이다 |
| 422 | 입력이 잘못됐다(가입일 형식 등) |
| 503 | 검색·DB 장애. **이때만 우리 잘못이다** |

기권을 503으로 내보내면 클라이언트가 "근거 없음"과 "서버 장애"를 못 가린다.
