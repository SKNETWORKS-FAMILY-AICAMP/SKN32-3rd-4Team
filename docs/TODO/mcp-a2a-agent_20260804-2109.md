## 하지 않기로 한 것

- **MCP 가 유스케이스·어댑터를 직접 부르지 않는다.** 라우터를 거친다.
  (커머스 시절 각자 래핑해서 두 경로가 어긋났다)
- **기권을 예외로 던지지 않는다.** `needs_expert` 는 정상 결과다 —
  예외로 만들면 에이전트가 재시도 루프에 빠진다.
- **런타임 설정 리소스에 키·시크릿을 싣지 않는다.** 화이트리스트로만 내보낸다.

---

## 에이전트가 오해하기 쉬운 것 (llms.txt 에 박아 둠)

1. 기권은 오류가 아니다 (`needs_expert` + HTTP 200)
2. 면책 목록에 없다 ≠ 보장된다
3. `data_source` 를 무시하지 마라 (`synthetic` 은 실제 통계가 아니다)
4. `admin_attested` 는 발행처 확인이 아니다
5. 제출은 검증이 아니다 (`unverified` 로 접수된다)
