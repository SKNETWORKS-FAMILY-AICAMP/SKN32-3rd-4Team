## 하지 않기로 한 것

- **차원을 상수로 박지 않는다.** 모델이 정하는 값이다.
- **거리 하한 없이 상위 k 를 그대로 돌려주지 않는다.** 그러면 호출자가 무관한 조항을
  근거로 받는다 — "확인 불가"가 정답인 경우가 있다.
- 모델을 바꾸면서 **거리 임계를 그대로 두지 않는다.**

## 겪은 함정 (되풀이 금지)

- **테스트가 차원을 하드코딩**하고 있었다(`[0.0] * 768`). 릴리스가 1024d 로 올라간 순간
  `DataException` — 어댑터에는 "차원은 모델이 정한다"는 교훈이 이미 적혀 있었는데
  테스트에 반영되지 않았다. 지금은 `ix.embed_dim()` 을 쓴다.
- 시각화가 **옛 DB 수치**를 달고 있었다 → `docs/reports/debugs/`.
