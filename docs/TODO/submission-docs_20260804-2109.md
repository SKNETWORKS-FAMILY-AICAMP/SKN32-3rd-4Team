## 문서 규칙 (이 저장소에서 지켜 온 것)

- **수집·전처리 결정은 리포트로 남긴다.** 코드 주석만으로는 "왜"가 사라진다.
- **숫자에는 분모를 함께 적는다.** 기준선이 바뀌면 분모도 바뀐다.
- **단위를 이름에 넣는다.** 표 `고유`와 `부착`은 다른 수다.
- **디버그·오진 기록을 남긴다**(`docs/reports/debugs/`). 다음 사람이 되풀이하지 않도록.
- **"구현 완료"를 백엔드·테스트 통과만으로 쓰지 않는다.** 화면이 있으면 열어서 확인한다.
