### ★2026-08-04 에 잡은 치명적 버그

**라이브니스 클래스 축을 잘못 읽어 아무도 얼굴을 등록할 수 없었다.**
`prob[0]` 을 live 로 읽었는데 MiniFASNet 출력은 `[2D-spoof, live, 3D-spoof]` —
실제 얼굴의 0번 값은 0.0001~0.003 이고 임계가 0.50 이라 **100% 거부**됐다.

★**테스트 14개가 전부 통과하는 동안** 그랬다. 기존 시험이 죄다
`relax_liveness`(임계 0.0)를 쓰거나 값의 **범위만** 봤기 때문이다 —
`0.001 >= 0.0` 은 참이다. **임계값을 낮춰 초록불을 만드는 것이 결함을 가렸다.**

지금은 `_LIVE_CLASS = 1` 상수 + **기본 임계값에서** 통과를 단언하는 시험이 있다.

## 하지 않기로 한 것 (데이터 취급)

- **녹음·영상·얼굴 원본을 저장하지 않는다.** 얼굴은 임베딩만 남긴다.
- **판정·집계 로직은 이 어댑터들을 모른다.** 음성으로 묻든 텍스트로 묻든 같은 유스케이스를 탄다.
- 얼굴 인증은 **접근 허용만** 결정한다.
- UI 에 **자기 자신을 관리자로 만드는 버튼을 두지 않는다**(승격은 CLI 전용).
