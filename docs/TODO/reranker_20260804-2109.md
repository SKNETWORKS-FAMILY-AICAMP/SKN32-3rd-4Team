## 지금 상태 (실측 2026-08-04)

```
INSURANCE_CLAUSE_RERANK_ENABLED = False   ← 기본 꺼짐
RERANKER_MODEL          Qwen/Qwen3-Reranker-4B   (S6 bake-off 승자)
RERANKER_FALLBACK_MODEL BAAI/bge-reranker-v2-m3  (저지연 대안)
CLAUSE_RERANK_MAX_CANDIDATES 40 · CONCURRENCY 1
```

★**커머스 `RAG_RERANK_ENABLED` 와 분리했다.** 같이 쓰면 커머스를 지울 때 보험이 함께 꺼진다.
모델 설정은 공유하되 **켜고 끄는 스위치와 관측은 나눈다.**

★기본이 꺼져 있는 이유: **4B 리랭커를 요청 안에서 동기로 돌리는 것은 프로토타입 한정**이다.
운영으로 켜려면 전용 워커·동시성 제한·타임아웃이 먼저 필요하다.

## 다음에 할 일

### P1

- [ ] **판정 경로에 리랭커를 켤지 결정한다.**
      완료 기준: 결정과 근거가 이 파일에 적히고, 켠다면 지연 상한이 함께 정해진다.
      판단 재료:
      - 켰을 때 Hit@k 개선폭(리포트에 실측 있음)
      - 요청당 추가 지연(4B·GPU 1개·동시성 1)
      - 시연 중 다른 GPU 작업과 겹치면 OOM
- [ ] 켠다면 **타임아웃 시 동작**을 정한다.
      ★조용히 원래 순서로 돌아가면 그건 폴백이다 — 감사 신호를 남긴다.
- [ ] 리랭커 없이도 인용 품질이 충분한지 **먼저 재본다.** 안 켜도 되면 그게 최선이다.

## 하지 않기로 한 것

- **커머스 리랭커 플래그를 재사용하지 않는다.**
- **기본값으로 켜지 않는다.** 워커·동시성·타임아웃이 갖춰지기 전에는 프로토타입이다.
- 조용한 폴백 금지 — 리랭킹을 건너뛰었으면 그 사실이 관측에 남아야 한다.
