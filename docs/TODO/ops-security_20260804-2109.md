## 하지 않기로 한 것

- **role 을 JWT 에 넣지 않는다.** 토큰에 박으면 권한 강등이 만료 전까지 반영되지 않는다.
- **UI 에 자기 자신을 관리자로 만드는 버튼을 두지 않는다.** 승격은 CLI 전용.
- **PII 마스킹이 값을 바꿨을 때 조용히 덮지 않는다.** 안전하게 가리되 감사기록을 남긴다.
- **원본 이미지·녹음·영상을 저장하지 않는다.**
- **실제 사용자 의료자료를 모델 학습에 쓰지 않는다.**

## 겪은 함정 (되풀이 금지)

- 역할 값 대소문자를 틀리면(`admin` vs `ADMIN`) `InfraError`("데이터 오염")로 **명시 거부**된다.
  이게 맞는 동작이다 — 조용히 USER 로 떨어지지 않는다.
- 관리자 계정을 만들 때 **알려진 비밀번호를 남기지 않는다.** 검증용 계정은 쓰고 지운다.
