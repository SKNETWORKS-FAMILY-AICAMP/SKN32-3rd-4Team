## 하지 않기로 한 것

- **고객 포트에 운영 화면을 노출하지 않는다.** `_OPS_STATIC` 이 물리적으로 404 로 막는다.
- **못 불러온 것을 "지원 안 함"으로 그리지 않는다.** 다른 사실이다.
- **판정 가능 약관이 0건이면 첫 화면에 그렇게 쓴다.** 빈 화면으로 두지 않는다.

## 겪은 함정 (되풀이 금지)

- ★**패널 제목이 화면에서 안 보였다.** `style.css` 의 **요소 선택자**
  `header { background:#2f3640; color:#fff }` 가 `<header class="panel-header">` 까지 칠하고,
  `.panel h2 { color:#2f3640 }` 와 겹쳐 어두운 배경에 어두운 글자가 됐다.
  **테스트는 전부 통과하고 있었다** — 화면을 열어야만 보이는 종류다.
- ★**브라우저가 옛 파일을 쓰고 있었다.** `Cache-Control` 이 없어 브라우저가 유효기간을
  제 마음대로 정했다. 서버는 새 파일을 주는데 화면엔 옛 이름이 떴다.
- ★**마크다운을 화면 문자열에 쓰지 않는다.** `textContent` 로 들어가면 `**강조**` 가
  별표째 보인다(실제로 `**10건(0.7%)**` 이 그대로 나왔다).
- 없어진 파일 이름이 차단 목록에 남아 있으면 **"막고 있다"로 읽힌다** — 막을 것이 없었다.
