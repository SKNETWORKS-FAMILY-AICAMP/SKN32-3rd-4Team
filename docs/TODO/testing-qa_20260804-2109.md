## 이 프로젝트에서 테스트가 놓친 것들 (전부 실제 사례)

| 무엇 | 왜 못 잡았나 |
|---|---|
| 얼굴 등록 100% 실패 | fixture 가 임계값을 0.0 으로 낮춤 |
| 패널 제목이 안 보임 | 화면을 열어야만 보이는 CSS 겹침 |
| 판정 모드가 반영 안 됨 | 그래프가 기동 시 값을 클로저에 가둠 |
| `by_verification` 유실 | dataclass 를 필드별로 재구성 |
| 매트릭스 가드가 한글 노드를 못 읽음 | 서브프로세스 인코딩 — **단독 실행 때만 통과** |

> 공통점: **초록불이 곧 동작은 아니다.** 화면이 있으면 열고, API 면 실제로 부른다.

## 하지 않기로 한 것

- **마커로 빼는 것과 "통과했다"는 다르다.** 뺐으면 무엇이 보증되지 않는지 적는다.
- **조용한 스킵 금지.** 건너뛴 건수를 세어 보고한다.
- **깨진 테스트를 폐기 딱지로 덮지 않는다.** 가리키는 파일이 정말로 없어야 폐기다.
