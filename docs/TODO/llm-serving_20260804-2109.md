## 지금 상태 (실측 2026-08-04)

```
LLM_PROVIDER        local (openai · gemini 선택 가능)
LOCAL_BASE_URL      http://127.0.0.1:8002/v1   ← 앱 개발서버(8000)와 충돌 피해 8002
ACTIVE_MODEL_PROFILE local_gemma4_e4b          ← model_registry.yaml 에서 해석
LLM_CHAT_ENABLED    True
요청 타임아웃        120s · 헬스체크 3s
```

★**모델 ID 를 소스에 하드코딩하지 않는다.** 설정은 **프로필 선택자**만 갖고
실제 ID·revision·checksum 은 `model_registry.yaml` 에서 해석한다.
`latest` 별칭은 레지스트리가 거부한다.

★**실행 스크립트가 `LLM_PROVIDER` 를 덮어쓰지 않는다.** `.env` 에서 고른 provider 가 실제 경로다.

## 하지 않기로 한 것

- **모델 ID 하드코딩 금지.** 레지스트리를 거친다.
- **빈 LLM 응답을 정상 답변처럼 반환하지 않는다** → `LLMOutputError`.
- **LLM 에게 날짜·면책기간·한도를 계산시키지 않는다.** 규칙엔진이 한다.
- 챗봇이 **보장 여부를 판정하지 않는다.**
